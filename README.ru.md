## Что это

Вы поручаете Claude Code или Codex CLI долгую задачу, отходите — и Mac засыпает, бросив работу на полпути. Vibe Awake живёт в строке меню и блокирует сон **только пока сессия генерирует ответ** — **в том числе с закрытой крышкой MacBook**.

В отличие от постоянно запущенного `caffeinate`, сессия, которая просто ждёт ввода, не мешает Mac уснуть как обычно. Заряд батареи не тратится впустую, пока вас нет.

## Установка

Требуется **macOS 13 (Ventura) или новее**.

### Homebrew

```bash
brew tap yamamoto7/tap
brew install --cask vibe-awake
```

Обновление и удаление тоже выполняются через Homebrew.

```bash
brew upgrade --cask vibe-awake
brew uninstall --cask vibe-awake   # удаляет и вспомогательный компонент
```

### Вручную

Скачайте `.dmg` со страницы [Releases](https://github.com/yamamoto7/vibe-awake/releases) и перетащите `Vibe Awake.app` в `Программы`.

## Настройка

При первом запуске **один раз** потребуется **пароль администратора**.

macOS позволяет запретить сон с закрытой крышкой только программе с правами администратора. Устанавливаемый компонент не делает ничего, кроме переключения встроенной настройки питания (`pmset`): без доступа к сети и без сбора данных. Его можно удалить в любой момент из настроек.

Пока настройка не завершена, блокировка сна не работает.

## Как пользоваться

Нажмите на значок в строке меню, чтобы увидеть текущее состояние.

- **Работает** — генерирует ответ или выполняет инструмент
- **Ожидает подтверждения** — ждёт, пока вы что-то подтвердите
- **Бездействует** — просто ждёт ввода

Залитый значок означает, что сон заблокирован. Оранжевый значок предупреждения означает, что настройка не выполнена.

## Настройки

| | |
|---|---|
| Блокировать сон | Временно отключает всё |
| Открывать при входе | Запускается вместе с Mac |
| Выключать дисплей при закрытии крышки | Пока сон заблокирован, macOS оставляет встроенный дисплей включённым при закрытой крышке. Выключение дисплея экономит энергию. При подключённом внешнем дисплее настройка не действует |
| Считать ожидание подтверждения работой | Включите, если подтверждаете удалённо, например с телефона. Если выключено, Mac уснёт, пока сессия ждёт вашего подтверждения |

## Языки

English, 日本語, 简体中文, 한국어, Español, Français, Deutsch, Português (Brasil), Русский. Приложение следует языку, выбранному в macOS.

## Важно знать

Определение состояния читает внутренние файлы, которые ни один из этих CLI не документирует, поэтому **обновление этих инструментов может всё сломать**. Если перестало работать, откройте [issue](https://github.com/yamamoto7/vibe-awake/issues).

Это неофициальный инструмент, не связанный с Anthropic или OpenAI. Claude, Claude Code и Codex — товарные знаки соответствующих владельцев.

## Сборка из исходников

Требуется Swift 5.9 или новее.

```bash
swift build                          # сборка для разработки
./Scripts/build_app.sh               # создаёт .app в dist/
./Scripts/check_localizations.sh     # проверяет актуальность переводов
```

Для сборки под распространение нужен сертификат Developer ID.

```bash
./Scripts/build_app.sh --release     # подпись Developer ID + Hardened Runtime
./Scripts/notarize.sh                # собирает DMG и отправляет на нотаризацию
```

### Переводы

Каждый язык — это файл `Localizable.strings` в `Resources/<lang>.lproj/`. Английский — язык разработки, поэтому недостающий в другом языке ключ подставляется из английского, а не отображается как есть. `Scripts/check_localizations.sh` сообщает о недостающих, неиспользуемых и неопределённых ключах — запускайте его после правки любых строк.

Обоснование логики определения состояния и проектных решений находится в комментариях к исходному коду.
