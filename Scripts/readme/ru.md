TAGLINE|Не даёт Mac уснуть — но только пока сессия ИИ-помощника действительно работает.
NOTE|При первом запуске один раз потребуется пароль администратора. macOS позволяет запретить сон с закрытой крышкой только программе с правами администратора → [Настройка](#настройка)
H_WHAT|Что это
P_WHAT1|Вы поручаете长 Claude Code или Codex CLI долгую задачу, отходите — и Mac засыпает, оставив работу на половине. Vibe Awake живёт в строке меню и блокирует сон **только пока сессия генерирует ответ** — **в том числе с закрытой крышкой MacBook**.
P_WHAT2|В отличие от постоянно запущенного `caffeinate`, сессия, стоящая на приглашении ввода, даёт Mac уснуть как обычно. Батарея не тратится, пока вас нет.

H_SETUP|Настройка
P_SETUP1|При первом запуске **один раз** потребуется **пароль администратора**.
P_SETUP2|macOS позволяет запретить сон с закрытой крышкой только программе с правами администратора. Устанавливаемый компонент не делает ничего, кроме переключения встроенной настройки питания (`pmset`): без доступа к сети и без сбора данных. Его можно удалить в любой момент из настроек.
P_SETUP3|Пока настройка не завершена, блокировка сна не работает.
H_USING|Как пользоваться
P_USING|Нажмите на значок в строке меню, чтобы увидеть текущее состояние.
L_WORKING|**Работает** — генерирует ответ или выполняет инструмент
L_WAITING|**Ожидает подтверждения** — ждёт, пока вы что-то подтвердите
L_IDLE|**Простой** — стоит на приглашении ввода
P_ICON|Залитый значок означает, что сон заблокирован. Оранжевый значок предупреждения означает, что настройка не выполнена.
H_SETTINGS|Настройки
S_ENABLE|Блокировать сон
S_ENABLE_D|Временно отключает всё
S_LOGIN|Запускать при входе
S_LOGIN_D|Запускается вместе с Mac
S_DISPLAY|Выключать экран при закрытии крышки
S_DISPLAY_D|Пока сон заблокирован, macOS оставляет встроенный экран включённым за закрытой крышкой. Его выключение экономит энергию. При подключённом внешнем дисплее ничего не происходит
S_APPROVAL|Считать ожидание подтверждения работой
S_APPROVAL_D|Включите, если подтверждаете удалённо, например с телефона. Если выключено, Mac уснёт, пока сессия ждёт вашего подтверждения
H_LANGS|Языки
P_LANGS|English, 日本語, 简体中文, 한국어, Español, Français, Deutsch, Português (Brasil), Русский. Приложение следует языку, выбранному в macOS.
H_CAVEATS|Важно знать
P_CAVEAT1|Определение состояния читает внутренние файлы, которые ни один из этих CLI не документирует, поэтому **обновление этих инструментов может всё сломать**. Если перестало работать, откройте [issue](https://github.com/yamamoto7/vibe-awake/issues).
P_CAVEAT2|Это неофициальный инструмент, не связанный с Anthropic или OpenAI. Claude, Claude Code и Codex — товарные знаки соответствующих владельцев.

H_TRANS|Переводы
P_TRANS|Каждый язык — это файл `Localizable.strings` в `Resources/<lang>.lproj/`. Английский является языком разработки, поэтому недостающий в другом языке ключ подставляется из английского, а не показывается сырым. `Scripts/check_localizations.sh` сообщает о недостающих, неиспользуемых и неопределённых ключах — запускайте его после правки любых строк.
